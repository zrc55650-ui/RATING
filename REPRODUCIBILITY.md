## Rebuild commands

From the repository root:

```powershell
$env:UV_CACHE_DIR = Join-Path (Get-Location) ".uv-cache"
uv run --no-sync python ./make_all_results.py
uv run --no-sync python ./export_figures_pdf.py
```

The first command regenerates the analysis CSVs, Markdown reports, SVG figures,
figure-source CSVs, and `numbers_for_paper.json`. The second command exports
the SVG figures to PDF and PNG.

## Required checks

After rebuilding:

1. Confirm `workstream_F_consistency_audit.md` reports technical
   consistency `PASS`.
2. Confirm cohort denominators are 600/2400, 1730, and 511/1514.
3. Confirm all displayed point estimates lie inside their 95% intervals.
4. Confirm the pure semantic effect equals Target effect minus Placebo effect.
5. Confirm `numbers_for_paper.json`, tables, and figure-source CSVs agree.
6. Visually inspect all four main figures.
7. Record an independent second-human numerical signoff before submission.

## Current validation limitation

The completed Judge Audit currently reports 88.0% binary agreement and a
maximum absolute condition bias of 3.4 percentage points. It does not clear
the pre-specified 90% hard-stop gate. Until remediation is complete,
automated outcome labels and outcome-dependent headline estimates remain
candidate values rather than frozen paper values.

Local API request/response files, worker logs, credentials, browser profiles,
and temporary caches are intentionally excluded from version control.
